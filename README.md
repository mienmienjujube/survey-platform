# 智能学术实验问卷平台

本系统是一款用于学术研究（如传播学与行为科学）的智能实验问卷平台，支持完整的前后测实验流程控制、AI 上下文隔离及数据导出。

---

##  快速体验 HTML 交互示例 (Demo)

如果您希望**秒级体验**完整的实验问卷交互流程，无需安装任何依赖与数据库环境：
* **体验方式**：直接双击打开项目根目录下的 **`academic-survey-demo.html`**。
* **主要特性**：单 HTML 文件自包含，完美集成了知情同意书倒计时、前测习惯调查、核心学术阅读与 AI 互动对话框（支持自由提问且 AI 自动解答）、后测问卷以及纯客户端数据打包与脱敏 CSV 下载功能。

---

## 部署与运行完整系统

本系统基于 Next.js 与 SQLite 开发。按照以下步骤可在本地或局域网环境一键运行：

### 1. 配置环境变量
复制根目录下的 `.env.example` 并重命名为 `.env`，修改相关参数：
```env
DATABASE_URL="file:./dev.db"
DEEPSEEK_API_KEY="您的 DeepSeek API Key"
ADMIN_USER="admin"
ADMIN_PASSWORD="您的管理员密码"
```

### 2. 安装依赖并初始化数据库
在项目根目录下打开终端，执行以下命令：
```bash
npm install
npx prisma db push
```

### 3. 启动项目
在项目根目录下，您可以选择以下任一方式启动系统：

* **方式一：Windows 快速启动 (推荐)**
  双击运行根目录下的 **`一键启动问卷平台.bat`**。
  > 脚本将自动检测您的局域网 IP，配置 Windows 防火墙端口，并启动平台服务。

* **方式二：命令行手动启动**
  ```bash
  npm run dev
  ```
  启动后，在浏览器中访问：
  * **问卷前台**：`http://localhost:xxxx`
  * **管理后台**：`http://localhost:xxxx/admin` (使用 `.env` 中配置的管理员账号密码登录)

##  数据管理后台
* **路径**：`/admin`
* **功能**：包含受试者账号一键批量生成、受试者实验进度跟踪、测试数据重置、以及一键导出全量实验数据为 SPSS/R 语言兼容的 CSV 和 XLSX 表格。
