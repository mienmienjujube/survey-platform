# 基于前后测实验设计的智能学术实验问卷平台

本系统是一款为学术研究（特别是传播学、教育学和行为科学）量身定制的**智能实验问卷平台**。系统基于前后测实验设计（Pre- and Post-test Experimental Design），旨在探究生成式人工智能（Generative AI）干预对人类认知表现、材料理解与批判性思维的影响。

## 🌟 核心特性

- **严格的实验流程控制**：
  - **登录验证**：通过唯一受试者账号进入，支持自动分配实验组/控制组状态。
  - **知情同意书（Consent Form）**：提供必读倒计时，确保受试者知情同意后进入实验。
  - **前测阶段（Pre-test）**：收集基本人口统计学特征、基准认知能力及初步的态度与行为倾向。
  - **过渡阶段（Transition）**：清晰指引受试者进入核心实验任务。
  - **后测与 AI 互动阶段（Post-test）**：受试者在阅读复杂材料的同时，可与内置的 AI 助手进行对话交互。
  - **问卷完整性校验**：执行严格的后测题目完成度校验，确保数据的高效与真实。
  - **完成确认（Thanks Page）**：感谢受试者参与，自动终止 Session。

- **多阶段 AI 对话上下文隔离（AI Context Isolation）**：
  - 核心实验包含多个不同的材料段落。为保证实验数据的科学性，系统为每个材料段落配置了**独立的 AI 上下文环境与提示词（System Prompt）**。
  - 受试者在不同任务间的对话互不干扰，完全避免了前置任务的对话历史对后续任务产生污染。

- **强大的数据导出与分析管道**：
  - **多格式导出**：内置安全的管理员面板（/shoowjo），支持一键导出 CSV 与高保真 XLSX（Excel）格式的实验数据。
  - **AI 对话记录格式化**：将受试者与 AI 的交互对话按“提问”和“回答”结构化转译为文本段落，便于研究人员进行文本分析（Text Analysis）或质性编码（Qualitative Coding）。
  - **实时进度保存**：受试者填写的每一步进度都会实时保存至本地数据库，防止因网络意外断开或浏览器崩溃导致数据丢失。

- **实验安全性与防作弊机制**：
  - 客户端安全性加固：限制鼠标右键菜单、禁用 F12 开发者工具，并拦截常用的快捷键组合（如 Ctrl+Shift+I、Ctrl+U 等），极大程度防止受试者在实验过程中篡改页面结构或答案。

- **极致的视觉交互设计**：
  - 采用毛玻璃拟物化（Glassmorphism）与现代响应式设计，极佳的排版与平滑微动效，减少受试者在长达一小时的实验过程中的疲劳感。

## 🛠️ 技术栈

- **前端/后端框架**：Next.js (App Router)
- **数据库 ORM**：Prisma Client
- **数据库引擎**：SQLite (轻量无阻碍，非常适合实验室局域网物理机快速部署)
- **文件导出**：SheetJS (xlsx)

## 🚀 实验室快速部署指南

本系统专门针对局域网（如高校计算机机房）部署进行了脚本级优化，无需复杂服务器运维基础即可一键运行。

### 前期准备

1. 确保服务器/本地物理机已安装 **Node.js** (推荐 v18 或更高版本)。
2. 本地克隆本仓库代码：
   ```bash
   git clone <你的 GitHub 仓库地址>
   cd survey-platform
   ```

### 步骤一：配置环境变量

在项目根目录下，将 `.env.example` 复制并重命名为 `.env`：
```bash
copy .env.example .env
```
用文本编辑器打开 `.env` 文件，进行如下修改：
```env
DATABASE_URL="file:./dev.db"
DEEPSEEK_API_KEY="填写您的真实 DeepSeek API Key"
ADMIN_USER="设置您的管理员账号"
ADMIN_PASSWORD="设置您的管理员密码"
```

### 步骤二：初始化数据库

在项目根目录下打开命令行，运行以下命令生成本地 SQLite 数据库：
```bash
npm install
npx prisma db push
```

### 步骤三：一键启动（Windows 环境）

- **普通模式**：直接双击运行根目录下的 `一键启动问卷平台.bat`。
- **专业/实验室部署**：
  1. 系统会通过 `start-lab.ps1` 脚本**自动获取当前物理机的局域网 IP**，并**随机生成一个高位可用端口**（如 18274）。
  2. 脚本会调用 Windows 防火墙自动为该随机端口开放入站规则（Inbound Rule），确保局域网内的受试者客户端物理机可直接通过 `http://<服务器IP>:<端口>` 访问问卷。
  3. 控制台会以绿色和黄色字体醒目输出**受试者访问链接**与**管理员后台链接**。

## 📊 数据管理与管理后台

- **管理员后台路径**：`http://<服务器IP>:<端口>/shoowjo`（该路径可防止受试者轻易猜出并误入）。
- **认证方式**：页面受 Basic Authentication 保护，请输入在 `.env` 中设置的管理员账号和密码。
- **后台功能**：
  - 实时受试者参与进度跟踪。
  - 生成指定数量的受试者随机账号（用于实验登录凭证）。
  - 一键清理/重置测试数据。
  - 导出全量实验数据为 XLSX 或 CSV 表格。
